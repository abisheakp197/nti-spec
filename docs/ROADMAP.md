# NTI Roadmap (12 months)

This roadmap is public and covers the twelve months following lab submission. It is
framed against the LFDT lifecycle criteria so progress can be reviewed against a
concrete target.

## Quarter 1 — Submission and baseline

- File the LFDT Lab Proposal (the `lab-proposals` issue form).
- Enable the branch-protection ruleset on both repositories (see
  [LFDT-READINESS.md](../LFDT-READINESS.md)).
- Register the OpenSSF Best Practices badge for both repositories and publish it.
- Produce the first Sigstore-signed release of the reference implementation so the
  Scorecard `Signed-Releases` check scores.

## Quarter 2 — Independent validation

- Commission a formal, independent third-party security audit of the reference
  implementation and the receipt-verification algorithm.
- Publish the audit report and remediate findings.
- Grow the conformance-vector suite and add a second independent implementation path.

## Quarter 3 — Diversity and adoption

- Add at least one maintainer from a second organization, to meet the LFDT Incubation
  diversity criterion of two or more maintaining organizations.
- Publish at least two independent adoption or integration references.
- Hold public community calls and record them in the repository.

## Quarter 4 — Toward Incubation

- Reach the LFDT Incubation entry criteria across Legal, Diversity, and Security.
- Submit a request to move from Lab toward an LFDT Incubation project.
- Publish a mid-year/annual report to the TAC.

## Standing commitments

- All technical discussion in public (GitHub issues and pull requests).
- DCO sign-off on every commit.
- A vulnerability disclosure policy in both repositories.
- Dependency scanning (Dependabot) and CodeQL on every pull request.
