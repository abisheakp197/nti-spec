# only when it is hash-verified, so CI installs from this file with
# `--require-hashes`. Every entry MUST carry a --hash, and the full transitive
# set must be listed, because --require-hashes rejects anything unhashed.
#
# requests is used by scripts/check_links.py. All wheels are universal
# (py3-none-any), so the hashes below work on every runner platform.
#
# ube-foundation is a native wheel, so every platform's artifact is hashed;
# pip installs the one matching the runner and ignores the rest. It is here
# because conformance/validate.py executes the Python blocks in the Markdown,
# and the CanaryGuard integration example calls the real engine. Installing it
# means CI verifies that example against the published artifact instead of
# failing on a missing import.
