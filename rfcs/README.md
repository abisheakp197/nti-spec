# NTI-1 Requests for Comments (RFCs)

This folder holds amendment proposals to the NTI-1 specification.

## How to Propose a Change

1. Open a new Markdown file `NNNN-short-title.md` in this folder.
2. Include: Summary, Motivation, Detailed Design, Drawbacks, Alternatives.
3. Open a pull request.

## RFC Lifecycle

- **Draft** — Being written
- **Proposed** — Under review (30 days)
- **Accepted** — Merged into spec
- **Rejected** — Closed with reason
