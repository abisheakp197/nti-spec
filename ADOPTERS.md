# Adopters

This file records organizations and projects that implement, deploy, or build
on the Neutral Trust Infrastructure (NTI) specification. It follows the LF
Decentralized Trust
[Defining Adopters](https://lf-decentralized-trust.github.io/governance/governing-documents/defining-adopters/)
guidance: entries should reference publicly verifiable usage.

> **Note on status:** Entries below are implementations and integration partners
> that build on or interoperate with NTI-1 at defined boundaries. They are listed
> with links to their public repositories. This list is expected to grow, and we
> invite anyone implementing NTI-1 to open a pull request adding themselves.
